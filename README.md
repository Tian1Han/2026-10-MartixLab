# 每周课后作业提交说明

本仓库用于提交 **第五期「强化学习与 MotrixLab 入门」** 课程的每周课后作业。

作业文件统一放在 `Week/` 目录下，按周次命名。本 README 仅用于说明目录结构、命名规范和周次索引，不展开具体题目与答案内容。

## 目录结构

```text
main/
├── README.md
└── Week/
    ├── Week1.md
    └── Week1.pdf
```

说明：

- `Week/`：存放每周课后作业；
- `WeekN.md`：第 N 周作业的 Markdown 版本；
- `WeekN.pdf`：第 N 周作业的 PDF 版本，与对应 Markdown 文件内容一致；
- `README.md`：作业提交说明与周次索引。

后续新增周次作业时，继续保持 `WeekN.md` 和 `WeekN.pdf` 的命名方式，并在下方周次索引中追加对应记录。

## 周次索引

| 周次 | 课程范围 | 作业类型 | Markdown | PDF | 附件 |
|---|---|---|---|---|---|
| Week1 | 第一周（第 1~4 讲） | 选择题 | [Week1.md](Week/Week1.md) | [Week1.pdf](Week/Week1.pdf) | — |

> 附件列用于预留后续可能加入的代码、数据、图片或其他补充材料；当前无附件时填写“—”。

## 命名规范

- 第 N 周 Markdown 文件：`WeekN.md`
- 第 N 周 PDF 文件：`WeekN.pdf`
- 所有周作业统一放在 `Week/` 目录下；
- Markdown 与 PDF 为同一周作业的同内容版本。

例如：

```text
Week/
├── Week1.md
├── Week1.pdf
├── Week2.md
├── Week2.pdf
└── ...
```

## 使用方式

- 通过上方“周次索引”快速定位每周作业；
- 阅读 `Week/WeekN.md` 查看对应周次的 Markdown 版本；
- 阅读 `Week/WeekN.pdf` 查看对应周次的 PDF 版本；
- 后续新增作业时，在 `Week/` 目录中加入文件，并在“周次索引”表格中追加一行。

## 备注

- 本仓库仅用于课程学习与课后复盘；
- 作业内容与解析以对应周次的 Markdown / PDF 文件为准；
- 如后续课程更新或题目调整，以课程官方说明为准。
